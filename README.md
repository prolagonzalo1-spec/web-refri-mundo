# Refri Mundo — sitio web

Página institucional de Refri Mundo: quiénes somos, qué hacemos y contacto por WhatsApp.

## Estructura

```
index.html        Página completa (todas las secciones)
css/styles.css    Estilos y paleta de colores
js/main.js        Menú móvil y animaciones
img/              Imágenes optimizadas que usa la página
material/         Material original (no se usa directamente en la web)
CNAME             Dominio propio para GitHub Pages
```

## Cambios frecuentes

- **Número de WhatsApp:** buscar `5491125291029` en `index.html` y reemplazarlo en todos los lugares.
- **Mensaje de WhatsApp:** buscar `Hola%20Refri%20Mundo%2C%20me%20contacto%20para...` (los espacios van como `%20`).
- **Horarios:** sección `Contacto` en `index.html`.
- **Colores:** variables al principio de `css/styles.css`.
